* TODO model refresher's info logs never reach Cloud Logging
~model_refresher/main.py~ builds a bare ~logging.getLogger(__name__)~ with no
level set and no handler, so the root logger's default WARNING threshold drops
both info lines: "Promotion event received for version N" and "Revision rollout
requested for <service>". Confirmed absent across three publishes to
~model-promoted~ on 2026-08-30.

Only the success path is blinded — ~logger.exception~ on the rollout failure
path is above threshold and does show up (the 2026-08-23 Artifact Registry
permission traceback is in the logs). But the success path is the one you want
when checking whether a real promotion rolled the backends, and without it the
only evidence is the new revision name plus the ~MODEL_REFRESH_AT~ value on the
service.

Fix with ~logging.basicConfig(level=logging.INFO)~ at import, or
~logger.setLevel~.
